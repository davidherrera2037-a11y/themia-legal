# Themia Legal — Sitio Web

Landing page de **Themia Legal, Firma de Abogadas**. Construida con Next.js, TypeScript, Tailwind CSS.

## Antes de publicar

Reemplaza las imágenes de ejemplo en `public/images/` por las reales, con estos nombres exactos:

- `logo.png`
- `hero.jpg`

Instrucciones detalladas en `public/images/LEEME.txt`.

## Cómo publicar este sitio

La guía completa, paso a paso y sin necesidad de saber programar, está en el
documento **"Guía de implementación — Themia Legal"** que Claude entregó junto
con esta carpeta.

## Solo si algún día usas esto desde tu computador (opcional)

```bash
npm install
npm run dev
```

Y abre http://localhost:3000 — pero para publicar el sitio real **no hace
falta hacer esto**, todo se hace desde el navegador (ver la guía).
